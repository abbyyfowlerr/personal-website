# Abby's personal website

A small, responsive, static website with warm ivory, forest green, and blue accents.

## Preview locally
Open `index.html` in a web browser. For a local server, run `python3 -m http.server 8000` in this folder, then visit http://localhost:8000.

## Edit
- `style.css` controls fonts, colors, and spacing.
- Each `.html` file corresponds to a page.
- Replace the placeholder GitHub, LinkedIn, and email links on the homepage.
- Edit all sample text to suit what you're comfortable sharing publicly.
- The fonts are loaded from Google Fonts and need an internet connection; local fallbacks are provided.

## Publish on GitHub Pages
1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, main, /(root).
4. Visit https://YOURUSERNAME.github.io after deployment.

No build tools or paid services required.
